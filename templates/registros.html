Cómo generar tokens y enviar registros
  1. Escribe el nombre de la herramienta y pulsa Crear token.
  2. Copia el token y el comando que aparecen arriba. El token no se vuelve a mostrar.
  3. La herramienta (o un pequeño colector en su servidor) hace un POST a la URL con la cabecera Authorization: Bearer <token>; cada POST guarda un registro.

El token es un secreto de servidor: no lo pongas en el JavaScript del navegador. Si la herramienta no puede hacer HTTP, un colector puede leer su archivo de log y reenviar cada línea con este mismo contrato.

curl -X POST https://www.urbenserver.com/api/ingesta \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"tipo":"log","texto":"hola","ruta":"/","usuario":"yo"}'

Campos recomendados: tipo, fecha (ISO 8601), ruta, usuario, texto y datos. Cualquier JSON extra se guarda tal cual. Si incluyes fecha o idempotencia, los reintentos no duplican el registro. Si pierdes un token, borra la fuente y crea otra; los registros anteriores se conservan.
